# 浮屿 vkr.me — FLO

FLO 浮宇宙的数字母港，一个以深夜海面、微光、留白和靠岸感为核心的单页沉浸式官网。

## 本地开发

启动本地开发服务：

```bash
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 预览。

## 构建

```bash
npm run lint
npm run build
```

项目使用静态导出，构建产物位于 `out/`，可部署到 Cloudflare Pages。
